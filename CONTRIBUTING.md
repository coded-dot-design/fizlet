# Contributing

Pull requests welcome. Before you open one, run `npm run check`, `npm run test`, `npm run test:browser`, `npm run size` and keep them green. Keep the contract in README.md; no runtime dependencies.

## Daily contest entries

No backend yet: enter on GitHub. Open an issue titled `Contest <date>: <your prompt>` (60 characters or fewer), or open a PR that adds your animation under `site/gallery/` with `"contest": "<date>"` and your `"author"` id on its entry (and `site/contributors/<id>.json` if you are new). One entry per person per day; the build checks both. Rules: https://fizlet.com/contest/
