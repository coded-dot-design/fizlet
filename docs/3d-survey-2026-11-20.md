# 3D survey, 2026-11-20: what seven games built by hand

Read from anonymous shallow clones of each game's default branch on 2026-11-20. Paths are in the game's
repository; line numbers are from that day's head. "Engine" is `@fzlt/core` at `main` (0.27.0 plus
Unreleased). Line counts of what a game would drop are counted from the listed ranges, not measured
builds.

## The short version

- **No game builds 3D out of DOM elements.** A search of every `src/` and `tests/` for `perspective`,
  `rotateX`, `rotateY`, `rotate3d`, `translateZ`, `translate3d`, `preserve-3d` and `matrix3d` finds
  three decorative uses (Holeshot `src/game.css:14`, a menu floor grid; DOM Battlefield
  `src/style.css:5096` and `5274-5295`, boot-screen doors; its `src/launch-effects.ts:56-58`, a
  `translate3d` with z = 0). Holeshot, CitySmash, Salvo Bay, Dune Hop and Orbiters draw 3D on a canvas
  through `@fzlt/core/diorama`; DOM Battlefield and DOM Crossfire are top-down 2D.
- **No game has its own matrix math, painter's sort or z-index by depth**, with one exception
  (Orbiters' projection, below). Depth order is the diorama's clusters and layers everywhere.
- **Built in two or more games, now bricks:** a model turntable (2 games, 3 copies) →
  `@fzlt/core/turntable`; ground painting through the diorama's projection (4 games) →
  `@fzlt/core/ground`.
- **Most hand-built 3D is an engine feature the game predates.** `behind`, `eye()`, `occlude()`,
  `rank: "depth"`, `terrainWindow`, `haze`, `water` and `props` each have a game still carrying the
  code they were lifted from. Those are ports in the games, not gaps in the engine (table at the end).
- **No type workaround on diorama was found.** `off` is on `DioramaObjectDef` since 0.27.0
  (`src/diorama.ts:52`); Holeshot's `src/modes/desert/look.ts:77-97` passes it with no cast and pins
  `^0.27.0`. The casts that exist are on the game's own endless-ground windows
  (`as unknown as Terrain & { x0: number; z0: number }` at `desert/world.ts:306`, `bigair/line.ts:187`,
  `wheelie/open.ts:797`), which `terrainWindow` replaces.
- **Inertia and snap are in no game.** Both turntables follow the pointer and stop. The brick has
  them as options that are off by default.

## Candidates checked and not built

- **Depth-sorted layers with a perspective helper**: the diorama is that already (clusters, layers,
  `behind`, `rank: "depth"`, `project`); no game sorts by hand.
- **Pick and grab against projected shapes**: one game (CitySmash), and its rules are the game's.
- **A pose or keyframe helper on `rig`**: two games hold pose tables (Holeshot's tricks, CitySmash's
  walls), but each is interpolated from that game's own timers and channels; the shared part is
  `rig`'s solve, in PR 380.
- **A light direction shared across props**: every game sets one light per palette through the
  diorama's `light` option and `setLight` (CitySmash `src/scene.ts:45`, Holeshot
  `desert/look.ts:22`, Salvo Bay `src/scene.ts:33`, Dune Hop `src/game.ts:49`); props already take
  the diorama's. Nothing to add.
